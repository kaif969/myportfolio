# My Portfolio

A responsive personal portfolio website built with **HTML** and **CSS**.

## Overview

This repository contains a clean, single-page portfolio template for presenting:
- Introduction and hero section
- About section
- Services / project work
- Portfolio gallery
- Contact section

## Tech Stack

- HTML5
- CSS3
- Google Fonts (Montserrat)

## Project Structure

```text
myportfolio/
├── index.html
├── style.css
└── assets/
    ├── about.jpg
    ├── bg.png
    ├── header.jpg
    └── project-*.jpg
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/kaif969/myportfolio.git
   ```
2. Open the project folder.
3. Launch `index.html` in your browser.

## Customization

- Edit text content in `index.html`
- Update styles in `style.css`
- Replace images in `assets/`
